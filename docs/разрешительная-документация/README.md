# Разрешительная документация ИЖС

> ⚠️ **Оговорка об актуальности:** раздел собран **07.11.2026** — сроки, размеры плат и формы заявлений меняются; перед действием сверяй действующие нормы и свой муниципалитет. Личные данные из реальных документов (номера договоров, адреса, ФИО) публикуются только в обобщённом виде — фактура остаётся в приватном репозитории.

## Главное, что путают новички

Для ИЖС в уведомительном порядке **разрешение на строительство не требуется** — только **уведомления** (о начале и об окончании). Разрешение нужно при исключениях (долострой, особые зоны) — проверь ст. 51 ГрК РФ, если твой случай пограничный.

## Жизненный цикл документов

```
До проектирования:     ЕГРН → ПЗЗ → ГПЗУ
До стройки:            уведомление о начале строительства
Параллельно стройке:   техприсоединение (электричество, газ, вода)
После стройки:         уведомление об окончании → техплан → регистрация права
```

## Правила подраздела

- Реальные PDF хранятся в приватном репозитории («стройка»); сюда — методика, сроки, чек-листы и обезличенные примеры.
- Каждая цифра (срок, плата) — с датой проверки; устарело — правка коммитом.
- Конфликт «инструкция из интернета против администрации» решается в пользу администрации — документы дают они.
